Couple photographs
------------------
Add up to three photos here, named:
  couple-1   couple-2   couple-3   couple-4   couple-5
Any of these formats works: .jpg  .jpeg  .png  .webp  (any size)
Each photo fills its frame automatically (cropped to fit, focused slightly above centre for faces).
Tip: big phone photos (5-10 MB) load slowly for guests; resizing to about 1500 px tall keeps the site fast.
Windows tip: turn on "File name extensions" in File Explorer > View so the name doesn't become couple-1.jpg.jpg.

Couple portrait (the large arch in "The Couple" section)
  portrait   (.png, .jpg, .jpeg or .webp)
A hand-drawn / illustrated portrait looks best (like the reference video). A normal photo works too.

"Our Favourite Moments" is a stack of up to five photo cards (couple-1 … couple-5).
As guests scroll, each photo slides off to the side to reveal the next one.
