Background music
----------------
Put your song here named:  wedding-music.mp3
(.m4a, .wav and .ogg also work with the same name.)
Music never plays until a guest taps "Open Invitation" or the Music button.
If no file is found, a gentle veena-and-tanpura tune plays instead.
Windows tip: turn on "File name extensions" in File Explorer > View, so the file isn't saved as wedding-music.mp3.mp3.
Note: the Claude preview link can't see files on your computer; your song plays on the site you publish (Netlify etc.).
